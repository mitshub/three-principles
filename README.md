# Three Principles Initiative
**Security · Water · Education**

A data-driven framework for solving humanity's greatest challenges.

🌐 https://three-principles.org

## About
This project visualises the state of three foundational rights
across 163 countries, based on:
- Global Peace Index 2025 (IEP)
- WHO/UNICEF Joint Monitoring Programme 2024
- UNDP Human Development Index 2022
